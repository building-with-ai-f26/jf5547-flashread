Summarize sends the extracted words to OpenRouter through this computer's local server. The PDF file and its name stay here, and nothing is sent until you click. Readings longer than 6,000 characters send only the beginning. Do not summarize a document you are not allowed to send to a third-party AI service.

The PDF stays on this computer. The page reads its text in the browser with PDF.js. A scanned PDF is a picture of the page, so this version cannot pull words out of it. Loading the page needs an internet connection so PDF.js can download. Playback events go to PostHog. The PDF text, file name, and summary text do not.
